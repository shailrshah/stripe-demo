Why might this say “pending”?

Being redirected here doesn't prove the payment succeeded: anyone can open this URL. The order's status changes only when the server receives a signed Stripe webhook (for example checkout.session.completed or payment_intent.succeeded). This page just shows the latest status, checking once a second for up to 30 seconds while it's still pending.
